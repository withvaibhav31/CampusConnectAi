# CampusConnectAi
A full-stack web application built with Node.js, Express, MongoDB, and EJS — featuring an AI recommendation engine

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB, Mongoose |
| **Authentication** | JWT (JSON Web Tokens), bcryptjs |
| **Templating** | EJS |
| **File Uploads** | Multer |
| **AI / Recommendations** | Custom rule-based recommendation system + keyword-based NLP |
| **Optional AI** | Gemini API integration ready |
